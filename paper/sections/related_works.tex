\section{Related Work}
Methods for discrete random variables provide further ways to handle a mixture's
categorical selector. Concrete and Gumbel--Softmax use a smooth,
temperature-controlled approximation and differentiate the resulting relaxed
objective \citep{maddison2017concrete,jang2017gumbel}. REBAR uses a continuous
relaxation as a control variate with a correction that preserves unbiasedness
for the discrete objective \citep{tucker2017rebar}. RELAX learns a differentiable
control variate jointly with the model \citep{grathwohl2018relax}. ARSM constructs
coupled categorical samples through augmentation and category swaps, sharing
randomness to reduce gradient variance \citep{yin2019arsm}. These approaches
offer alternatives for optimizing mixture selection probabilities.

Other work extends pathwise differentiation to broader continuous families.
Generalized reparameterization combines a sample derivative with a score
correction for parameter-dependent transformed noise \citep{ruiz2016generalized}.
\citet{naesseth2017rejection} derive gradients through acceptance--rejection
samplers, enabling applications to distributions such as Gamma and Dirichlet.
These methods provide useful directions for extending the component families
supported by ReMix. For the initial implementation, an existing PyTorch package
for implicit mixture gradients provides a software reference
\citep{simkusMixture}; the discussion of mixture sampling derivatives in PyTorch
issue \#39178 gives additional implementation context \citep{pytorch39178}.
