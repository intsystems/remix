\section{The ReMix Library}
\label{sec:library}
ReMix\footnote{\url{https://github.com/intsystems/remix}} represents an
unbatched mixture with a vector of logits and PyTorch components that share
an event shape and base measure. The user supplies the model log density to
\texttt{ELBOObjective}. A call to \texttt{estimate(q, objective)} returns
an \texttt{EstimateResult} with a detached \texttt{value} for logging and
a scalar \texttt{surrogate\_loss} whose gradient is the negative of the
estimated ascent direction (Fig.~\ref{fig:training-step}).

\begin{figure}[htbp]
 \centering
 \input{figures/training-step}
 \caption{One training step. The loop sends the returned loss to PyTorch's
 backward pass and reads the objective estimate from the same result.}
 \label{fig:training-step}
\end{figure}

The estimator determines which samples reach the objective
(Fig.~\ref{fig:estimator-calls}). \texttt{ScoreFunction(n\_samples=$n$)}
draws $n$ mixture points. \texttt{Stratified(n\_samples=$n$)} draws $n$
points from each of the $K$ components and weights the $K$ sample means.
Both call \texttt{ELBOObjective.evaluate} on a batch of points. With
\texttt{stl=True}, the objective evaluates the mixture log density with
detached distribution parameters so gradients still flow through its input.
\texttt{Implicit} uses scalar or factorized continuous components with
differentiable CDFs.

\begin{figure}[htbp]
 \centering
 \input{figures/estimator-calls}
 \caption{Sampling and objective calls inside \texttt{estimate}.
 The two branches show \texttt{ScoreFunction} and \texttt{Stratified}. Both use the same
 objective to evaluate $\log p(x,z)-\log q_\theta(z)$.}
 \label{fig:estimator-calls}
\end{figure}

\noindent\begin{minipage}{\linewidth}
Listing~\ref{lst:remix-training} fits the weights of two Gaussian components
to a target mixture with weights $0.2$ and $0.8$. Using the target's log
density as the model makes the ELBO the negative Kullback--Leibler divergence
from the fitted mixture to the target. Either estimator in the listing
evaluates 32 points per update.

\begin{lstlisting}[style=remixpython,caption={Fitting mixture weights at a matched sampling budget.},label={lst:remix-training}]
import torch
from torch.distributions import Normal
from remix import ELBOObjective, Mixture, ScoreFunction, Stratified

components = [Normal(-2.0, 1.0), Normal(2.0, 1.0)]
target = Mixture(torch.tensor([0.2, 0.8]).log(), components)
logits = torch.nn.Parameter(torch.zeros(2))
objective = ELBOObjective(target.log_prob, stl=True)
estimator = Stratified(n_samples=16)  # or ScoreFunction(n_samples=32)
optimizer = torch.optim.Adam([logits], lr=0.05)

for step in range(300):
    optimizer.zero_grad()
    result = estimator.estimate(Mixture(logits, components), objective)
    result.surrogate_loss.backward()
    optimizer.step()
print(result.value.item(), logits.detach().softmax(dim=-1))
\end{lstlisting}
\end{minipage}\par
